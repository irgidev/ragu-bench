# results/

Committed benchmark artifacts. Everything here is produced by real runs; nothing is hand-edited to look better.

- `runs/` one `RunRecord` JSON per model run (written by the harness; schema in `src/bench/schemas.py`)
- leaderboard and routing tables: markdown generated from run records
- charts: PNG generated by the metrics stream
- `REPORT.md`: final recommendations with the numbers behind them
